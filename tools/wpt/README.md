# web-platform-tests extractor

`extract-css-color-parsing.php` turns the static test data of
[web-platform-tests](https://github.com/web-platform-tests/wpt) `css/css-color/parsing` into the
fixture `fixtures/reference/wpt/css-color-parsing.json`. It is plain PHP and runs no JavaScript;
cases generated by JavaScript expressions are counted in `meta.skipped_by_extractor`.

To regenerate for another WPT commit:

```bash
COMMIT=$(git ls-remote https://github.com/web-platform-tests/wpt.git refs/heads/master | cut -f1)
mkdir -p /tmp/wpt && cd /tmp/wpt
for f in color-valid color-valid-rgb color-invalid-rgb color-computed-rgb \
         color-valid-hsl color-invalid-hsl color-computed-hsl \
         color-valid-hwb color-invalid-hwb color-computed-hwb \
         color-valid-lab color-invalid-lab color-computed-lab \
         color-valid-color-function color-invalid-color-function color-computed-color-function \
         color-invalid-hex-color color-computed-hex-color \
         color-invalid-named-color color-computed-named-color \
         color-valid-color-mix-function color-invalid-color-mix-function color-computed-color-mix-function \
         color-valid-relative-color color-invalid-relative-color color-computed-relative-color; do
  curl -fsS -o "$f.html" "https://raw.githubusercontent.com/web-platform-tests/wpt/$COMMIT/css/css-color/parsing/$f.html"
done
cd - && php tools/wpt/extract-css-color-parsing.php /tmp/wpt "$COMMIT" > fixtures/reference/wpt/css-color-parsing.json
```

Review the diff like a code change, then run `composer test:conformance`. The WPT license
(3-Clause BSD) is kept in `fixtures/reference/wpt/LICENSE.md`.

## Canvas compositing

`extract-canvas-composite.php` turns the Porter–Duff tests of `html/canvas/element/compositing`
(`2d.composite.solid.<operator>.html` and `2d.composite.transparent.<operator>.html` for 11
operators) into `fixtures/reference/wpt/canvas-composite.json`:

```bash
mkdir -p /tmp/wpt-canvas && cd /tmp/wpt-canvas
for v in solid transparent; do
  for op in source-over source-in source-out source-atop destination-over destination-in \
            destination-out destination-atop xor copy lighter; do
    curl -fsS -o "2d.composite.$v.$op.html" \
      "https://raw.githubusercontent.com/web-platform-tests/wpt/$COMMIT/html/canvas/element/compositing/2d.composite.$v.$op.html"
  done
done
cd - && php tools/wpt/extract-canvas-composite.php /tmp/wpt-canvas "$COMMIT" > fixtures/reference/wpt/canvas-composite.json
```
