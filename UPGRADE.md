# Upgrade guide

This file describes, for every release with an impact on users, **what changed, why, and how to
migrate** (with code). It covers changes of the public API, of default methods or constants, and of
numeric results, which are all part of the compatibility promise.

Before 1.0, minor releases may change the API; every such change is listed here.

## [0.1.0]

Initial release. There is nothing to migrate from.
